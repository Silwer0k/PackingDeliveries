# PackingDeliveries

Система для автоматизации планирования загрузки посылок в грузовики. Позволяет создавать уникальные формы грузов, визуализировать их размещение и экспортировать результаты в JSON или текстовые отчеты.

## 🚀 Основные возможности

*   **Умная упаковка**: Несколько алгоритмов размещения (SMART, EVENLOAD, ONEBYONE) с учетом физической опоры груза.
*   **Гибкие формы**: Создание посылок любой формы с помощью текстовых шаблонов.
*   **Telegram Interface**: Полное управление через бота (команды `/create`, `/packing`, `/find` и т.д.).
*   **Консольный интерфейс**: Управление через команды в консоли
*   **Импорт/Экспорт**: Поддержка работы с JSON-файлами для сохранения и восстановления состояния грузовиков.
*   Одновременный запуск как бота Telegram и консольного интерфейса

📐 Алгоритмы упаковки
* SMART: Сортирует грузы по убыванию размера и заполняет грузовики максимально плотно.
* EVENLOAD: Распределяет груз равномерно между всеми машинами, следя за балансом объема.
* ONEBYONE: Простейшее распределение "одна посылка — в один грузовик".

## 📋 Консольные команды

1.  **Создание посылки**:
    `CREATE -name "Посылка А" -form "xxx\nxxx" -symbol "@"`
    Форма упаковки определяется сиволом "x" для обозначения ячейки формы посылки, " " (пробел) - пустой ячейки, "\n" - следующего уровня (строки) формы посылки
3.  **Упаковка**:
    `PACKING -parcels-file "list.txt" -trucks "3" -type "SMART" -out text`
    *(Поддерживаются типы ввода: -parcels-file, -parcels-text)*
    *(Поддерживаются типы вывода: -out text, -out json-file -out-filename "packed_trucks")*
5.  **Поиск**:
    `FIND "Имя посылки"` или `FIND all`
6.  **Удаление**:
    `DELETE "Имя посылки"`
7. **Распаковка**:
   Распаковка грузовиков представленных в файле в формате JSON в файл посылок
   `UNPACKING -infile "infile.txt" -outfile "outfile.txt"`

## Команды Telegram-бота

1.  `/create` - создание посылки
2.  `/find` - поиск посылки по имени/всех
3.  `/delete` - удаление посылки
4.  `/packing` - упаковка посылок в указанное количество грузовиков
5.  `/unpacking` - распаковка грузовиков формата json
    Формат команды идентичен соответствующей консольной команды
